# GPT-OSS Train-source style pilot

Collect a fourth local generator family separately from the frozen A capacity
fits. This pilot tests generation on actual admitted sources after the synthetic
[compatibility request](GPT_OSS_GENERATOR_V1.md). It neither changes the live
training archive nor selects a remedy from unfinished Train-fit diagnostics.

Use the same pinned GPT-OSS checkpoint, tokenizer and installed MLX environment
as that request. Keep weights unchanged. Override only the Jinja template's
`strftime_now("%Y-%m-%d")` expression with the literal `"2026-09-15"`. Require
exactly one replacement, retain both templates and bind the resulting bytes in
the model specification and campaign plan. Keep the default medium reasoning
effort. Record rendered prompts and token IDs before any inference. Use a
dedicated loopback server on the Studio with one request at a time, no prompt
cache, temperature 0.7 and a 4,096-token completion limit. Set the request deadline
to 1,800 seconds and retain incomplete or uncertain attempts without automatic
retries. Do not restart shared services.

Take the first hash-ranked human root from each of the four collections in the
already frozen [Train register packet](TRAIN_REGISTER_REVIEW_V1.md). Reproduce
its original ranking against all 471 human Train roots, preserving exact source
bytes, historical-proxy evidence, rights, group IDs and splits. Each selected
root must equal its original Train record. Selection uses no detector result
or output quality. The four roots concern a novel, missing data, a cardiac-cell
study and film awards. Keep source defects and relative dates as supplied.

For each root, request one independently composed draft under each of these
existing `style-mix-v1` profiles, in order: `source-matched`, `plain`, `informal`,
`direct`, `anti-ai`, `fix-slop`. Use six single-profile campaigns, each containing
the same four roots, for 24 planned requests. Preserve the existing prompts and
their prohibition on added facts, changed qualifications, stance and argumentative
relationships. Do not substitute the garden prompt or impose an exact word count.
Freeze all 24 prospective requests before launching the first campaign. Start
with `source-matched`; inspect its execution and output before the remaining
campaigns. Continue the declared profiles unless an execution problem requires
a documented pause. Never replace a failed source or select styles by A scores.

Keep every raw response, final channel and admission failure. The collector's
length, completion, source-copy and record checks remain in force. A complete
cohort export is only a collection result. Read every source and generated final
passage, including complete outputs rejected by the copy/length checks. Record
omissions, invented details, qualification and relationship changes, realized
register, tone and copying separately from provenance. Historical publication
is weak human-origin evidence. Assistant review is not independent human gold.

Fidelity failures remain recorded model attempts. They cannot establish a
controlled effect of style while holding meaning fixed. No pilot record enters
the active fits or release corpus automatically. Any later expansion or training
comparison needs a declared admission policy and recipe after the frozen A
diagnostics are complete. This pilot makes no detector or Pangram requests and
does not use private B, CIT, correspondence or held-out hosted captures.
