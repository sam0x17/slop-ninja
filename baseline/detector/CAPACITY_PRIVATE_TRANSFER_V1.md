# Private transfer check for the larger A candidates

Apply the existing [private transfer protocol](ORIGIN_PRIVATE_TRANSFER_V1.md)
to both candidates from the [larger-backbone experiment](CAPACITY_LARGE_V1.md).
Keep the same three complete texts, V6 observations, saved Pangram annotations
and editorial reservations. The source family was already inspected and its
edits were chosen against V6. This remains a diagnostic of a known failure,
not fresh confirmation or training data.

Prepare a separate plan before either large candidate is available. Bind the
large training snapshot and public comparison, this protocol and the original
private protocol, the unchanged base private plan, and every source/evidence
file required by that plan. Reproduce the three V6 document reports with the
same frozen Rust reporter. Verify that the base and large checkpoint tokenizer
assets are identical; retain their hashes. Do not overwrite or retarget the
base comparison. All identifying manifests and text-bearing artifacts remain
in private Studio storage outside the repository and datasets.

Run only after both large fits close successfully, both sizes' fixed public
comparisons complete, and the base private comparison has complete evidence.
Verify the original calibration thresholds and artifact bindings for all four
candidates before comparing their private results. Keep both control and
consistency candidates regardless of their public scores. This requirement
does not change when the base comparison may run under its own protocol.

For each large candidate and each source version, follow the original document
prepare, CPU inference and reporting steps. Require the original source hash,
token count and window layout. Score every emitted request once, preserve
terminal status and partial failures, and report direct whole-document scores
separately from window diagnostics. No new Pangram request, automatic retry,
threshold adjustment, text edit or candidate substitution is part of this check.

Report each large candidate against V6 and against its corresponding base
candidate, along with the within-size control/consistency contrasts. Retain
every source version, its model-plus-assistance probability, its flags at both
frozen operating points and its change from the original version. Reuse saved
Pangram content fractions only for these exact texts. Do not equate those
fractions with A's classification probabilities or infer population correlation
from three versions of one document.

A smaller disagreement on these known edits is useful evidence only alongside
human false positives, calibration and the other fixed comparisons. The study
compares two pretrained backbones under one recipe; any difference cannot be
attributed to parameter count alone. Fresh source/style/generator confirmation
and independent editorial review remain necessary before reference promotion
or using the new detector to optimize B.
