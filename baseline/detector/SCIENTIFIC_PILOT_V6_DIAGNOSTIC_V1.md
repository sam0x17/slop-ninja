# V6 diagnostic on the closed scientific pilot

Score the three historical human introductions and all 23 captured drafts from
the fixed 24-request scientific pilot. Thirteen drafts passed origin admission;
ten were excluded for copied source spans. The remaining request timed out
without captured text. Preserve that failure without a score or replacement.
All captured drafts have complete source-relative reviews and fail strict
fidelity. Freeze the completed review before opening detector scores.

The sources were allocated to Train for later data expansion. Neither V6 nor
the active control/consistency fits consumed this new cohort. The three shared
source families, uneven realized styles, substantive changes and source copying
limit what this diagnostic establishes. It is not a style-only experiment or
an independent population benchmark. Report generator/profile slices and human
controls without treating related drafts as independent sources.

Use the frozen V6 artifact
`4e061df4789e546dfdd58c8005860a98fb8f200a4c7642b7491461f44f16f138`,
its bundled float32 eager CPU runner, calibration and 2,048-token limit. Run on
Studio using the runner's single-thread default. Keep complete texts and verify
the token counts against the prior uncapped audits. Unexpected failures or
binding mismatches stop reporting; preserve the responses for inspection.

Apply the existing strict greater-than thresholds, 0.8436493155285434 and
0.4287369114260753. Report the full distribution of scores and flags, supported
inputs and generation failures. Do not omit an excluded draft, a human control
or an inconvenient result. Keep automatic admission and fidelity judgments
unchanged. Missing generation text has no detector result.

The Rust preparer binds the review, source roots, protocol, artifact manifest,
generation-run metadata, exact requests/responses/profiles, admission outcomes
and campaign terminal record. It verifies the two-model, four-profile,
three-source matrix including the timeout. It also binds expected missing
capture files so a late response cannot silently alter the cohort. The reporter
shares V6 response validation with the long-pilot diagnostic while retaining
separate schemas, expected counts and limitations for each study.

This study makes no generation or Pangram calls, creates no training admission,
and changes no model, calibration or threshold. It may inform a revised data
recipe; it does not select existing drafts by score. The remaining 80 generation
calls stay paused. The running fits, their frozen comparisons, the larger-model
launch order and reserved confirmation sources remain unchanged. Pangram
alignment and useful edit gradients remain untested on these texts.
