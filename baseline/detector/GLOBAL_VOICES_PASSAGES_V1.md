# First contiguous publisher passages

Use the eight already reviewed HTML documents to nominate complete, contiguous
paragraph runs. This is source preparation for broader human coverage in A,
with no training admission, origin label, detector call or provider request.

Keep every selected work in the outcome ledger. Declare the paragraph boundaries
and reasons before materializing the passages. Use opening narrative runs ending
before a new heading, embedded region or an introduction requiring the following
quotation. Retain short candidates and unsuitable works explicitly; do not replace
them with more convenient articles. All eight works are exposed development data.

For each nomination, reparse the unchanged source with the versioned HTML view.
Require whole top-level paragraph siblings and no intervening nonparagraph region,
unwrapped prose, media, code or inline structural quotation. Unknown elements and
HTML recovery require inspection. A quoted term in an ordinary text node remains
in its paragraph. Do not jump across a removed region, insert a bridge or edit
source wording. Collapse Unicode whitespace within each paragraph, translate br
to a space and join paragraphs with two newlines. Declare this normalized text
view; it is neither exact HTML bytes nor browser rendering. Retain the original
HTML/artifact identity and all region boundaries separately.

Read each complete materialized passage against the prior whole-article review.
Record dangling references, missing qualifications or context, source defects,
attribution concerns and length separately from successful extraction. A short
opening or a complete sentence can still be an unsuitable training passage.
No single byline, old date or parse result establishes human-only production.
Commercial admission and historical evidence remain separate requirements.

Build and run on the Studio. Keep passage text and source artifacts outside Git;
publish only code, boundary metadata, aggregate results and review findings.
The active A fits, old extraction, grammar productions and corpus splits remain
unchanged. Later source expansion and confirmation need their own frozen cohort.
